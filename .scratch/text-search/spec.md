# Selectable text and search

Add a PDF.js text layer so readers can select and copy text, then search each document independently.

## Acceptance criteria

- Rendered pages expose selectable text aligned with the canvas.
- Search is case-insensitive and runs only when requested.
- Results report matching pages and total occurrences.
- Previous and next controls wrap across matching pages.
- The active matching page and matching text runs are visually highlighted.
